# Watermark Studio v2.3.3

本版修复「内容映射 / 交换主副」无实际作用的问题。

## 内容映射现在如何工作

文字图层的“内容映射”会把正文中的具体行指定为：

- 主标题
- 副标题

映射会直接参与排版模板计算，不再只是旧预设兼容字段。

### 自动映射

点击“自动映射”：

- 第一个非空行 -> 主标题
- 第二个非空行 -> 副标题
- 其余行 -> 辅助信息

### 手动映射

主标题映射、副标题映射现在都是行选择器，可直接指定正文中的任意非空行。

### 交换主副内容

点击“交换主副内容”后，主标题与副标题对应的正文行会真实交换，文本编辑框、画布、映射关系与当前品牌排版模板会同步更新。字符级字体、颜色等局部样式，以及行级光学偏移会跟随对应文字一起交换。该操作支持撤销与重做。

## 排版模板命名调整

前四个模板改为更明确的角色语义：

- 主标题强调 · 中
- 主标题强调 · 左
- 副标题强调 · 中
- 副标题强调 · 左

这样模板行为与内容映射一致，不再依赖“第一行 / 第二行”的固定假设。

## 兼容

旧项目中的 `brandPrimary` / `brandSecondary` 会自动迁移为新的行映射。保存后会同时保留兼容字段。

## v2.3.3 主副标题内容交换

「内容映射」中的按钮现在为 **交换主副内容**。

例如当前正文：

```text
FINN
AIGC
```

且主标题映射为 FINN、副标题映射为 AIGC。点击「交换主副内容」后，正文和画布都会立即变为：

```text
AIGC
FINN
```

此时主标题为 AIGC，副标题为 FINN。当前品牌排版模板会立即重新应用。局部字体、颜色等字符样式以及行级光学偏移会跟随对应文字一起交换，并支持撤销/重做。
